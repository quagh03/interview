- Code đã nói được thì không comment. `// tăng i` chỉ thêm nhiễu.
- Viết khi code không thể hiện ý định hoặc ràng buộc: vì sao phải chờ, vì sao chỗ này không được cache, vì sao giữ lại hành vi cũ.
- `TODO` phải kèm lý do. Sửa code thì sửa comment cùng lúc. Comment cũ nói sai còn hại hơn là không có comment.
