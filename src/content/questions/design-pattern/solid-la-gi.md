- Năm nguyên tắc để class và module dễ sửa, dễ test.
- **S**ingle Responsibility: một class một lý do để đổi.
- **O**pen/Closed: thêm hành vi mới mà không sửa code đã ổn định.
- **L**iskov Substitution: class con thay được class cha mà không làm hỏng chương trình.
- **I**nterface Segregation: interface nhỏ, client không phụ thuộc method nó không dùng.
- **D**ependency Inversion: module cấp cao phụ thuộc abstraction, không phụ thuộc class cụ thể.
